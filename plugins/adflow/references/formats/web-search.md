# Web search

The ad looks like an internet search: a search bar, autocomplete suggestions or a page of results.

Family: Static, native screenshot.
Back to the [gallery](../format-gallery.md) · rules in [format-classification.md](../format-classification.md).

## Must be true

- A search bar, autocomplete list or results page is visible and recognisable.
- A typed query is shown, often a question the viewer would type.
- The product appears as the answer, a result or next to the search.

## Not to confuse with

- **Notes app:** typed text in a phone note, no search bar.
- **Press:** an article page, not a results page.
- **Comment screenshot:** a comment under a post.

## Quick test

Does it look like someone's search bar or search results?

## Does not belong in the format

- The problem in the query, or a problem-aware audience: Angle and Awareness.

## Variants

- **Autocomplete:** a half-typed query with suggestions dropping down. Tag it as Web search.

## Examples

- ✅ A search bar "why does my dog itch after" with four suggestions, and the shampoo below as the answer.
- ✅ A results page for "best rain jacket for cycling" with the product as the top result, for a comparison angle.
- ❌ The same question typed in a phone note: Notes app.
- Real ads: the visual-formats library, files named `vf=web-search` (3 examples), and its notes in
  [formats/web-search](https://github.com/alyshadotmd/visual-formats/tree/main/formats/web-search).
  Library: <https://github.com/alyshadotmd/visual-formats/tree/main/files>.
