# Script frameworks voor DEAL / OFFER ads

Herbruikbaar over klanten heen. Voor korting-, bundel- en aanbod-ads (story, ~8–15s, tekst op scherm).
Deal-ads mogen de **prijs op de eindkaart** tonen (wijkt bewust af van de zachte-CTA-regel voor organische ads).
Elk framework heeft een psychologisch profiel (Zone / Anchor / Intensity). De voorbeelden hieronder zijn
**generieke placeholders** (`<…>`) — klant-agnostisch.

> **Klant-agnostisch bestand.** Ingevulde voorbeelden met echte producten/prijzen/klantwoorden horen op klantniveau:
> `clients/<klant>/deal-ad-examples.md` (bv. [`clients/full-of-yoga/deal-ad-examples.md`](../clients/full-of-yoga/deal-ad-examples.md)).
> Vuistregel: deal-ads leunen doorgaans naar **lower-funnel** (product/oplossingsbewust), **Medium–High intensity**.
> Varieer bewust de trigger (waarde, urgentie, bezwaar, cadeau) zodat je niet alles op korting-alleen test.

---

## 1. Value Stack → Price Drop  ·  `[Zone 1 / Ideal / Medium]`
Stapel eerst de waarde (wat krijg je allemaal), dán de prijs. Sterkst voor bundels.
**Structuur:** Hook (kijk wat je krijgt) → onderdeel 1 → onderdeel 2 → "los = hoge prijs" → dealprijs + besparing → CTA
```
Hook: Kijk wat er in deze <bundel> zit
- <onderdeel 1 + kernbenefit>
- <onderdeel 2 + kernbenefit>
- <compleetheids-regel>
- Los <ankerprijs> → samen <dealprijs> (bespaar <bedrag>)
- <CTA / merk-signatuur>
```

## 2. Better Together (bundel-synergie)  ·  `[Zone 4 / Ideal / Medium]`
Laat zien waaróm de onderdelen bij elkaar horen, dan de deal.
**Structuur:** Hook (ze horen samen) → wat elk doet → samen = compleet → deal → CTA
```
Hook: <A> én <B> horen samen
- <wat A doet>
- <wat B doet>
- Daarom nu als één bundel
- Van <ankerprijs> → <dealprijs> (bespaar <bedrag>)
- <CTA / merk-signatuur>
```

## 3. Anchor & Contrast (prijsanker)  ·  `[Zone 1 / Actual / High]`
Zet meteen het contrast: los duur ↔ samen goedkoper. Direct, cijfer-gedreven.
**Structuur:** Hook (apart = X) → wat je krijgt → samen nu → besparing → CTA
```
Hook: Apart <ankerprijs>. Samen nu <dealprijs>.
- <onderdeel 1 + onderdeel 2>
- <overkoepelende benefit>
- Nu samen in één bundel
- Jij bespaart <bedrag>
- <CTA / merk-signatuur>
```

## 4. Reason-Why / Urgentie  ·  `[Zone 2 / Actual / High]`
Geef een reden voor de deal + tijd/voorraad-druk. Lower-funnel, FOMO.
**Structuur:** Hook (reden + urgentie) → waarde → deal → schaarste → CTA
```
Hook: <reden voor de deal> — daarom deze <deal>
- <wat je krijgt>
- <kernbenefit>
- Van <ankerprijs> → <dealprijs> (bespaar <bedrag>)
- <schaarste/tijdsdruk>
- <CTA / merk-signatuur>
```

## 5. Objection-Crusher (niet kunnen kiezen)  ·  `[Zone 3 / Actual / Medium]`
Neem de twijfel weg ("welke moet ik nemen?") — de bundel lost het op.
**Structuur:** Hook (de twijfel) → bundel neemt het weg → waarde → deal → CTA
```
Hook: <de twijfel/keuzestress>?
- Nu hoef je niet te kiezen
- <A> én <B>, samen
- <overkoepelende benefit>
- Nu samen met <bedrag> korting (<dealprijs>)
- <CTA / merk-signatuur>
```

## 6. Cadeau-framing  ·  `[Zone 1 / Ought / Medium]`
Positioneer als cadeau (haak in op review-woorden als "aanrader", "leuk om te geven"), nu voordeliger.
**Structuur:** Hook (perfect cadeau) → waarom → deal → CTA
```
Hook: Het cadeau waar <doelgroep> blij van wordt
- <kernbenefit>
- <wat zit erin>
- Nu voordeliger: <dealprijs> (was <ankerprijs>)
- <cadeau-regel> · <merk-signatuur>
```

---
**Gap-tip:** met deze 6 dek je Zone 1/2/3/4, alle anchors en Medium–High intensity. Test niet 6 keer korting-alleen;
test verschillende triggers (waarde-stack, synergie, prijsanker, urgentie, bezwaar, cadeau) om te leren wát verkoopt.
Klantwoorden voor de invulling komen uit `clients/<klant>/reviews/`.
