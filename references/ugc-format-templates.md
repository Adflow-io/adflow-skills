## Tier-ranking (Dara Denney — "51 Meta Ad Creative Types", 20.000 ads)
Maak **S/A eerst**; B = supporting cast; C–F = laag/vermijden. Gecombineerd met de Motion-studie (spend-use ratio).

- **S (unicorn-scalers):** Founders content · Partnership ads (creators) · VSL
- **A:** Amateur investigation · Yapper (to-cam storytelling) · **David & Goliath** · **Grid-static** (bundels/meerdere SKU's) · **Authority ads** (expert) · Green-screen commentary · Catalog/DPA
- **B (supporting):** Callout · Before/After · Progression · Us-vs-Them · Headline · Creator low-fi statics · **Objection-handling** · **Comment-reply** · Educational infographic · **Challenging-your-beliefs** · Conversation · Founder's-letter · EGC · Mood board
- **C:** AI-animation · Statistics · Celebrity · AI-avatar · Warehouse · Street-interview · ASMR · ⚠️ **gewone problem-solution UGC (VO + B-roll)** = algemene fatigue
- **D:** Breaking-news · AI-billboard · **GRWM / Day-in-the-Life** (schaalt slecht op paid)
- **E:** Text-only · Testimonial-statics · Listicles · Carousel
- **F:** Press · Podcast · Notes-app/UX

**Algemene waarschuwing (geldt breed):** leun niet op problem-solution UGC met VO+B-roll (= de demo-structuur) →
fatigue; diversifieer. Welke tiers/formats een specifieke klant als drager kiest → `clients/<klant>/format-fit.md`.

## Formats + korte structuur
| Format | Kern |
|---|---|
| **Problem–Solution** | begin met een specifiek probleem → product als directe oplossing ("de klassieker") |
| **Demonstration / How-to** | laat zien hoe je 't gebruikt; voelt organisch (= de demo-structuur) |
| **Review Ad** | maker geeft "eerlijke mening"; bouwt vertrouwen, beantwoordt bezwaren. Varianten: zelf proberen · anderen laten proberen (blind) · rating |
| **Comparison ("This vs That")** | merk/aanpak X vs Y; snelle cuts, regel-voor-regel contrast |
| **Ugly Ads** | opzettelijk lage productie, rauw, one-take → valt op |
| **Day in the Life / GRWM** | product in de dagelijkse routine verweven |
| **Educational / Knowledge share** | algemene kennis of listicle ("3 redenen…") |
| **Personal History Angle** | storytelling, diepere persoonlijke ervaring → emotionele connectie |
| **Skits (sketches)** | gescript scenario, meerdere personages |
| **Talking Back and Forth** | maker speelt 2 rollen (slim vs minder slim); J-cuts |
| **Visual Format** | props/visuele hulpmiddelen om concept uit te leggen |
| **Voiceover Format** | beeld/foto's + voice-over eroverheen |
| **Multitasking** | tips terwijl je iets anders doet (koken, opruimen) |
| **Setting Change** | locatie verandert gedurende de video |
| **Shot/Angle Change** | elke ~2s ander shot/hoek |
| **Clone Format** | maker dubbelt zichzelf om te vergelijken |
| **Whiteboard** | whiteboard om een les uit te leggen |
| **Q&A** | iemand off-camera stelt vragen |
| **Green Screen** | relevante beelden achter de spreker |
| **Reaction video** | reageer op virale video + eigen expertise |
| **Product stress test** | product testen/uitdagen |
| **Flat lay** | product van bovenaf, netjes uitgelegd |
| **Point of View (POV)** | eerste-persoons perspectief |
| **Staged moment** | voelt echt, organische hook, naadloze demo, simpele CTA |
| **Walk and talk** | pratend terwijl je loopt ("caught in the wild") |
| **Before / After** | contrast begin- vs eindstaat |
| **Sticky notes** | boodschap via post-its |
| **RAW UGC** | ongepolijst, native-aanvoelend |
| **Challenges** | een challenge rond het product |
| **Talking head** | recht in de camera praten |
| **Founders Ads** | oprichter vertelt (zie subpagina "Founders ad frameworks") |
| **Warehouse ads** | POV vanuit magazijn/maker |
| **Calling customers** | (opgenomen) gesprek met klant |
| **Podcast style ads** | podcast-look (zie subpagina) |
| **Comment response** | reageer op een comment → ideaal voor bezwaren/FAQ |
| **Signs** | boodschap via borden/kaarten in beeld |
| **Actionable step + dream result** | "als je dit zoekt… probeer dit" |
| **AI animation** | claymation / AI-gegenereerd |
